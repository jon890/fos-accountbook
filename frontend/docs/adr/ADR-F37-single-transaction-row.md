# ADR-F37: 거래 목록은 공용 행 하나로 그리고 누르면 수정 시트를 연다 (2026-10-01)

- **status**: `accepted`
- **결정**: 지출, 수입, 달력 날짜 목록, 반복 지출은 `TransactionRow` 하나로 그린다. 행은 설명, `카테고리 · 작성자 · 시각`, 금액(지출과 수입을 색과 부호로 구분) 순으로 보인다.
  행을 한 번 누르면 수정 시트(`EditTransactionDialog`)를 연다. 행 안에 수정, 삭제 버튼을 두지 않고, 삭제와 반복 지출 종료는 시트 안에서 확인창을 거친다.
  날짜 머리를 누르면 달력의 그 날짜(`/calendar?month=YYYY-MM&date=YYYY-MM-DD`)로 간다. 추가 진입은 하단 탭 가운데 버튼 하나만 둔다.
- **맥락**: 모바일 목록이 보기 어렵다는 사용자 지적이 있었다(2026-10-01). 조사해 보니 같은 거래를 그리는 행이 네 종류였고 금액 표기도 네 가지였다. 수입 행은 금액이 12px 로 가장 작았고, 내역 탭에는 작성자가 보이지 않았다. 지출과 수입 행은 눌러서 펼친 뒤 다시 버튼을 눌러야 수정됐고, 펼친 줄에 32px 삭제 버튼이 수정 버튼 옆에 있었다. 추가 버튼은 세 군데 있었다.
- **대안 기각**:
  - 날짜 상세 화면을 새로 만들기: 달력 화면이 이미 날짜별 목록과 등록, 수정, 삭제를 갖고 있어 기능이 겹친다.
  - 행에서 밀어서 삭제: 실수로 지우기 쉽고, 웹에서 제스처 구현과 접근성 대응 비용이 크다.
- **결과**:
  - 얻는 것: 화면이 달라도 거래가 같은 모양이다. 한 번 눌러 수정한다. 행에 삭제 버튼이 없어 실수로 지우지 않는다.
  - 감당할 것: 행을 바꾸면 네 화면이 함께 바뀐다. 삭제가 한 단계 깊어진다(시트를 열고 삭제).
